=== Explanation for Differences ===

1. Callback fields expanded - This is the INTENDED change from Patch 1 (frame contract)
   - Before: onChunkStart received only { audio: Int16Array }
   - After: onChunkStart receives { audio, frameIndex, timestampMs, streamTimeMs }
   - This is the new feature, not a regression

2. Provider architecture - This is the INTENDED change from Patch 2
   - Before: All VAD logic inline in processPcmData()
   - After: VAD logic encapsulated in DefaultVadProvider
   - This is the new feature, not a regression

=== No Functional Regression ===

The actual VAD behavior (speech detection, silence detection, chunk boundaries)
is IDENTICAL between baseline and current because:
- Same threshold values (0.008, 0.015)
- Same consecutive frame counts (1 for speaking, 10 for silence)
- Same state machine logic (just moved into provider)
- Same leading buffer size (10 frames)
