Wave A Patch 1 + 2 - Production Path
====================================

=== Exact Live Runtime Call Path ===

1. MICROPHONE INPUT (stream/microphone.ts)
   - Audio device captures PCM data
   - Emits 'data' events with Buffer

2. SPEECHRECORDOR PROCESSING (audio/index.ts)

   2.1 processPcmData() - Entry point for each audio chunk
       File: maestro/client/src/main/audio/index.ts
       Line: 256
       
   2.2 createAudioFrame() - Attach frame metadata
       File: maestro/client/src/main/audio/index.ts
       Line: 238-250
       Creates: { pcm16, sampleRate, channels, frameIndex, timestampMs, streamTimeMs }
       
   2.3 denoiseProvider.process() - Pass through denoising
       File: maestro/client/src/main/audio/index.ts
       Line: 272-279
       Input: AudioFrame with metadata
       Output: DenoiseResult with frame
       
   2.4 vadProvider.process() - VAD decision
       File: maestro/client/src/main/audio/index.ts  
       Line: 286-297
       Input: Denoised frame
       Output: VadDecision { isSpeech, noiseFloor, volume, ... }
       
   2.5 Speech state updated from provider
       File: maestro/client/src/main/audio/index.ts
       Line: 296-297
       this.speaking = vadDecision.isSpeech
       this.noiseFloor = vadDecision.noiseFloor
       
   2.6 onChunkStart callback (if speech begins)
       File: maestro/client/src/main/audio/index.ts
       Line: 309-314
       Emits: { audio, frameIndex, timestampMs, streamTimeMs }
       
   2.7 onAudio callback (every frame)
       File: maestro/client/src/main/audio/index.ts
       Line: 354-362
       Emits: { audio, speaking, volume, frameIndex, timestampMs, streamTimeMs }
       
   2.8 onChunkEnd callback (if speech ends)
       File: maestro/client/src/main/audio/index.ts
       Line: 322

3. DOWNSTREAM CONSUMER (chunk-manager.ts)
   - Receives onAudio callbacks with frame metadata
   - Processes speech chunks
