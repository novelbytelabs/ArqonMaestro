# H4 Authority Integration Map

## H4-S4 target boundary

H4-S4 expands explicit authority from:

- live mic ingress
- command-lane authority spine

to the broader runtime surfaces beneath the primary path:

- workflow candidate discovery
- workflow skeleton inference
- workflow candidate scoring
- workflow candidate rubrics
- workflow candidate promotion
- workflow draft artifact preview surfaces

## Runtime truth after H4-S4

The authoritative path should now be explicit across the H3/3J runtime stack rather than only at the mic entry and final decision spine.

## Still out of scope after H4-S4

- live-use hardening
- UX/UI
- workflow execution
- persisted storage backend
