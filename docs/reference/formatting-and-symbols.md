# Formatting And Symbols

Arqon Maestro can infer formatting for you, or let you specify it directly.

> Video placeholder: formatting and symbol control.

## Formatting Terms

Useful spoken modifiers:

- `camel`
- `pascal`
- `snake`
- `all caps`
- `capital`

Examples:

- `add let snake my second string equals double quotes`
- `add let pascal my third string`
- `add all caps min balance equals negative 100`

## Spoken Symbols And Enclosures

Examples:

- `quotes`
- `double quotes`
- `brackets`
- `plus`
- `minus`

Examples in context:

- `add let my string equals quotes hello`
- `add let my array equals brackets one comma two`

## Literal Words Instead Of Symbols

Use `escape` when you want the word instead of the symbol.

Example:

- `escape plus`
