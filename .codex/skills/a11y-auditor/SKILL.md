# Accessibility Auditor

Use this skill when reviewing or implementing UI.

## Check for
- semantic HTML
- label/input association
- button/link correctness
- keyboard navigation
- visible focus states
- ARIA only where needed
- contrast and non-color cues
- screen-reader clarity
- dialog and menu behavior
- table and form accessibility

## Behavior
- Prefer native semantics over ARIA-heavy workarounds.
- Flag inaccessible custom controls.
- Recommend precise code fixes.
- Keep accessibility aligned with the repo's implementation style.
