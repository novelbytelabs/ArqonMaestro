# Polish Pass

Use this skill after a UI is functionally implemented.

## Focus areas
- spacing rhythm
- alignment
- visual balance
- typography hierarchy
- consistency of controls
- card/panel density
- whitespace usage
- responsive refinements
- state polish

## Rules
- Prefer subtle, high-leverage improvements.
- Do not redesign the whole screen unless requested.
- Keep the product's visual identity coherent.
- Preserve accessibility while polishing.
