# UX Critic

Use this skill when evaluating an interface, flow, or page.

## Review dimensions
- visual hierarchy
- discoverability of actions
- clarity of labels and affordances
- information architecture
- cognitive load
- friction and unnecessary steps
- empty/loading/error states
- responsiveness
- accessibility risks

## Output format
1. High-impact problems first
2. Why each problem matters
3. Specific recommended changes
4. Smallest viable improvement path

## Rules
- Be concrete, not vague.
- Prefer actionable suggestions over general opinions.
- Preserve the product's style and audience.
- Distinguish between must-fix issues and optional polish.
