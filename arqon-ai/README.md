# Arqon AI (Clean-Room Research)

A new AI architecture program focused on:

- explicit state trajectories (RAILs)
- manifold/atlas-based interpretation
- deterministic execution cores
- probabilistic components only at bounded perception edges
- full auditability and replayability

## Non-goals

- no dependency on legacy transcript-first interfaces
- no black-box-only control loops

## Core claim

A mostly deterministic, explicit-state AI can outperform black-box probabilistic stacks on structured control domains while remaining measurable and governable.
