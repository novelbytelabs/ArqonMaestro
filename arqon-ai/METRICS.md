# Metrics

## Core

- Task Success Rate (TSR)
- Safety Violation Rate (SVR)
- p50/p95 Action Latency
- Deterministic Replay Match Rate (DRMR)
- Trace Completeness Score (TCS)

## Efficiency

- CPU/GPU time per successful action
- Joules per successful action
- Memory footprint per active trajectory

## Interpretability/Governance

- Decision Reason Coverage
- Policy Explainability Coverage
- Unhandled Transition Count
