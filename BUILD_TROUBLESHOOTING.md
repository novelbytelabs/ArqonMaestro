# ArqonMaestro Build Technote

**Technical Details for Dependency Resolution**

---

## Build Error Analysis

### Error 1: Protobuf Version Mismatch

```
Protobuf compiler version 25.8 doesn't match library version 3.12.4
error: "This file was generated by a newer version of protoc which is incompatible with your Protocol Buffer headers"
```

**Root Cause**: 
- `build.gradle` pins `protobufVersion = "3.14.0"`
- System has protobuf 3.12.4 (Ubuntu 22.04 default)
- protoc 25.8 generated files that need protobuf 4.x headers

**Fix Options**:

1. **Install protoc 3.14.0** (match the build.gradle):
```bash
# Download protoc 3.14.0
cd ~/Projects/arqon/ArqonMaestro/.tools
curl -LO https://github.com/protocolbuffers/protobuf/releases/download/v3.14.0/protoc-3.14.0-linux-x86_64.zip
unzip protoc-3.14.0-linux-x86_64.zip -d protoc-3.14.0
rm protoc-3.14.0-linux-x86_64.zip

# Add to env.sh
export PATH="$MAESTRO_ROOT/.tools/protoc-3.14.0/bin:$PATH"
```

2. **Or update protobuf in build.gradle** (more work):
```groovy
def protobufVersion = "4.25.8"  // Match system protoc
```

### Error 2: Missing Marian NMT Library

```
No rule to make target '/home/irbsurfer/libserenade/marian/build/libmarian.a'
```

**Root Cause**: Marian NMT is not compiled. This is a C++ neural machine translation library used by code-engine.

**Fix**: Build Marian from source

```bash
# Marian build dependencies
sudo apt-get install -y \
    libboost-all-dev \
    libprotobuf-dev \
    protobuf-compiler \
    libssl-dev \
    libgoogle-perftools-dev \
    cmake \
    git

# Clone and build Marian
cd ~/libserenade
git clone https://github.com/marian-nmt/marian.git
cd marian
mkdir build && cd build
cmake .. -DCOMPILE_CPU=on -DCOMPILE_CUDA=off
make -j$(nproc)
```

**Note**: This takes 30-60 minutes to compile.

### Error 3: Boost Version Mismatch

```
Could not find a configuration file for package "Boost" that is compatible with requested version "1.78.0"
The following configuration files were considered but not accepted:
  /usr/lib/x86_64-linux-gnu/cmake/Boost-1.74.0/BoostConfig.cmake, version: 1.74.0
```

**Root Cause**: Ubuntu 22.04 ships Boost 1.74.0, but CMakeLists.txt requires 1.78.0.

**Fix Options**:

1. **Install Boost 1.78.0 from source**:
```bash
cd ~/libserenade
curl -LO https://boostorg.jfrog.io/artifactory/main/release/1.78.0/source/boost_1_78_0.tar.gz
tar -xzf boost_1_78_0.tar.gz
cd boost_1_78_0
./bootstrap.sh --prefix=$HOME/libserenade/boost
./b2 install -j$(nproc)
```

2. **Or patch CMakeLists.txt** (quicker):
```cmake
# In code-engine/server/CMakeLists.txt
# Change:
find_package(Boost 1.78.0 REQUIRED)
# To:
find_package(Boost 1.74.0 REQUIRED)
```

---

### Error 4: Missing Marian Headers

```
fatal error: common/timer.h: No such file or directory
```

**Root Cause**: This header is from Marian. The code-engine includes Marian headers but Marian isn't built.

**Fix**: Build Marian (see Error 2 above).

## Dependency Build Order

```
1. Protobuf 3.14.0 (protoc)
2. Boost 1.78.0 (or patch CMakeLists)
3. Marian NMT
4. Kaldi (for speech-engine)
5. Gradle build
```

## Quick Fix: Minimal Build

If you want to skip C++ engines initially:

```bash
# Build only Java components
cd ~/Projects/arqon/ArqonMaestro/serenade
gradle core:installd toolbelt:installd --exclude-task :code-engine:buildCMake --exclude-task :speech-engine:buildCMake
```

This gives you the Java control plane without the C++ engines.
